# BADLANDS // ПРОТОКОЛ «ПОБЕГ»

Стильный 3D веб-шутер от первого лица по мотивам **Cyberpunk 2077**.
Ви (девушка) угнала «Базилиск» и уезжает из Найт-Сити вместе с Панам — они любят друг друга,
и корпоративные эскадроны «Арасаки» не готовы это принять. Отбей волны преследователей в пустошах
и доведи танк до маяка эвакуации.

## Что внутри

- Полноценный **3D FPS на Three.js**: pointer lock, хитскан-стрельба, трассеры, взрывы, bloom, тени, закат Багровых пустошей, силуэт Найт-Сити на горизонте.
- **RPG-система**: опыт за убийства, уровни, выбор одного из трёх киберимплантов при каждом повышении (12 перков: «Бомомол», «Схлоп», «Кироши», «Титановые рёбра» и др.).
- **Киберимпланты и способности**: Sandevistan (замедление времени, `Q`), рывок (`Shift`), пассивная оптика «Кироши»; тяжёлые юниты роняют чипы с постоянными бонусами.
- **Арсенал**: пистолет «Кэнсин», SMG «Хикэцу», дробовик «Игла» — открываются по волнам.
- **Враги**: штурмовики корпо, дроны-камикадзе, тяжёлые юниты с очередями; у всех — полоски HP.
- Живой HUD: радар, витальные данные, кулдауны, урон по цифрам, радиопереговоры с Панам, сюжетные заставки, эпилог.
- Процедурный звук (WebAudio): выстрелы, взрывы, музыкальный пульс — без единого аудиофайла.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь / ЛКМ | обзор / огонь |
| ПКМ | прицеливание |
| R | перезарядка |
| 1 / 2 / 3 | оружие |
| Q | Sandevistan |
| Shift | рывок |
| Space | прыжок |
| Esc | пауза |

## Запуск локально

```bash
npm install
npm run dev        # разработка
npm run build      # продакшен-сборка в dist/
```

## Хостинг на GitHub (Pages)

1. Создай репозиторий на GitHub и запушь проект:

```bash
git init
git add .
git commit -m "BADLANDS: 3D cyberpunk web shooter"
git branch -M main
git remote add origin https://github.com/<ТВОЙ_НИК>/<ИМЯ_РЕПО>.git
git push -u origin main
```

2. В проекте уже лежит готовый воркфлоу `.github/workflows/deploy.yml` — он собирает игру
   (с правильным `--base` для Pages) и публикует её в GitHub Pages.

3. Включи Pages: **Settings → Pages → Source: GitHub Actions**.

4. Через 1–2 минуты игра будет доступна по адресу:

```
https://<ТВОЙ_НИК>.github.io/<ИМЯ_РЕПО>/
```

> Важно: сборка использует `vite build --base=./`, поэтому ассеты подхватываются
> и на поддомене `github.io`, и на кастомном домене.
